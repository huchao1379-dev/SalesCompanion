# 11 · 成功指标与收益度量

收益从三个维度展开：**销售个人体验**、**业务过程质量**、**组织规模化能力**。下列为设计目标值，须在 Phase 1 试点建立基线后再对比，避免空泛承诺。

## 度量三原则

1. **先基线后承诺**：Phase 1 测真实分布，再设对比目标  
2. **指标可监测**：用户行为日志 + Agent 调用日志 + Dataverse 读出；用自定义页面 / 视图呈现  
3. **季度公布**：未达标项进入下一季度 Agent / 体验优化清单  

## A · 个人体验：被迫使用 → 主动使用

| ID | 指标 | 目标方向 | 度量方式 |
| --- | --- | --- | --- |
| **A1** | 拜访录入耗时 | **≤ 30 秒 / 次** | 录音开始 → 草稿可见 / Confirm 的耗时分布 |
| **A2** | 每日被表单消耗时间 | 显著下降 | 时间日志或问卷自报告 |
| **A3** | 系统使用意愿（NPS / CSAT） | 被迫用 → 主动用 | Phase 1 末与 Phase 2 末各测一次 |

A1 说明：口语直接生成活动反馈 + 商机草稿，相对事后桌面补录 5–15 分钟压缩一个数量级。

## B · 过程质量：更新鲜、更完整、更可决策

| ID | 指标 | 目标方向 | 度量方式 |
| --- | --- | --- | --- |
| **B1** | 拜访记录时效性 | 次日补录 → **现场即录** | 拜访发生 → 系统落库时延中位数 |
| **B2** | 商机识别覆盖率 | 显著上升 | 商机新建（或有效追加）数 / 拜访数 |
| **B3** | 数据质量一致性 | 必填完整度 ↑ | 核心商机字段填写完整率 |
| **B4** | 售后响应速度 | 现场约 **10 秒内**得答案 | First-Time-Fix + 平均响应（Phase 3） |

B2 说明：商机评估 Agent 从拜访摘要提示线索，人确认，减少漏报。

## C · 组织能力：快交付、多区域、低耦合

| ID | 指标 | 目标方向 | 度量方式 |
| --- | --- | --- | --- |
| **C1** | 新功能交付节奏 | 季度 → **周** | Phase 2 后新增 Agent 平均上线时长 |
| **C2** | 多语种与多区域复用 | 一套 Agent · 多语言开箱 | 区域本地化工作量 vs 传统方案 |
| **C3** | 对 SAP 侵入度 | **零定制**（SAP 不动底座） | SAP 仅暴露既有 API，不新增功能 |
| **C4** | Citizen Developer 网络 | 区域专家可参与设计 | Phase 4 起各区域 Maker 数量与贡献次数 |

## 运营看板建议字段

| 类别 | 示例字段 |
| --- | --- |
| 体验 | 日活、语音成功率、草稿采纳率、编辑率、拒绝率 |
| Agent | 按 Agent 调用量、成功率、P95 延迟、Credits 估算 |
| 集成 | SAP 写入时延、SyncFailed 率、重试成功比 |
| 业务 | 拜访落库中位数时延、商机/拜访比、字段完整率 |

数据源：App Insights、AgentInvocationLog、Dataverse 业务表 / VT。

## 阶段门禁与指标绑定

| 阶段 | 最低度量动作 |
| --- | --- |
| Phase 1 末 | 建立 A1 分布基线；首轮 NPS；草稿采纳/拒绝率 |
| Phase 2 末 | A1–A3、B1–B3 复测；质量基线周更 |
| Phase 3 末 | 纳入 B4；知识类满意度 |
| Phase 4 | 季度全量公布；C1–C4 纳入运营例会 |

未达标 → **禁止**自动进入下一阶段扩量（见 [09](09-implementation-roadmap.md) 风险原则 ③）；豁免须 Sponsor 书面确认。
