# 01 · 产品总览

## 一句话定位

基于 **Microsoft Power Platform**，为销售团队打造 **移动优先、语音驱动、AI 编排** 的智能业务伙伴——让一线销售在客户拜访现场用一句话完成数据查询、活动反馈记录与商机创建，把 SAP Commerce CRM 的「完整能力」包装成「对话式体验」。

> 不再让销售「使用 CRM」，而是让 CRM「跟随销售」。

本仓库产品名：**SalesCompanion**（Power Apps Code App）。

## 设计原点

传统思路是把桌面 CRM 移植到手机上。本方案的设计原点是：把 CRM 拆解成可被语音召唤、可在对话中确认、可在后台自动落库的 **Agent**，让销售只与客户、不与表单打交道。

| 维度 | 目标 |
| --- | --- |
| 移动主流程 | ≤ 30 秒：语音录入活动反馈 → 商机草稿 |
| 覆盖业务域 | 客户活动 · 商机 · 订单 · 安装售后 · 考核管理 |
| Agent 规划 | 30+（含通用场景），分阶段上线 |
| 实施周期 | 6 个月四阶段；3 个月内首个生产 Agent 上线 |

## 现状与挑战

客户业务依赖高度定制的 **SAP Commerce CRM**。桌面端功能完整，但与一线销售现场工作严重错位。

### Pain 01 · 形态错配

所谓「移动端」多为桌面 Web 的 Responsive 包装：未按移动操作重设计；触控与导航仍是桌面思维；现场更倾向 Excel / 微信记录。

### Pain 02 · 性能瓶颈

跨境访问链路长，单页与列表常需数秒至十余秒，耐心被等待消耗。

### Pain 03 · 录入摩擦

「记录拜访」需填 10+ 字段（主题、纪要、时间、目的、联系人、状态、跟进、关联客户/商机等）。移动表单只是把痛苦从大屏迁到小屏。

### Pain 04 · 智能缺位

「是否建商机」「产品线是什么」「信心度多少」全靠人脑，再手动跳模块创建——正是 AI 最该介入却尚未介入的环节。

**核心判断：** 问题不在「CRM 该不该上移动端」，而在于：当 AI 已能理解口语、识别意图、调用业务 API 时，销售为何还要被迫填表？目标不是把桌面表单缩到 6 寸屏，而是让表单从用户视野中消失。

## 四条设计原则

每条原则 = 一句本质 + 一条硬规则。

### 原则 01 · Mobile-First，不只是 Mobile-Compatible

设计起点是「单手 · 户外光线 · 30 秒内完成」，而非桌面缩小版。

**Design Rule：** 单一焦点 · 一拇指可达 · 离线可写；超过 3 屏的表单必须由对话承接。

### 原则 02 · Voice-First，键盘是 fallback

语音是拜访间隙最自然的输入；键盘只在语音失败时出现。

**Design Rule：** 主页面常驻语音按钮 · 设备原生 Web Speech API 转写 · AI Builder 抽取字段，无额外语音订阅。

### 原则 03 · Confirm, Don't Configure

AI 主动给草稿，用户只做「确认 / 微调 / 拒绝」三选一。

**Design Rule：** 每条 AI 输出附「来源 + 置信度 + 一键编辑」；拒绝/编辑沉淀为提示词优化语料。

### 原则 04 · Agent 编排，不是菜单导航

用户表达意图，Generative Orchestration 调度 Agent，无需知道 SAP 菜单。

**Design Rule：** 移动端只有「对话 · 看板 · 任务」三入口；新增能力靠注册 Agent 而非重构 UI。

## 价值主张（三维）

详见 [11 成功指标](11-success-metrics.md)。摘要如下：

| 维度 | 方向 |
| --- | --- |
| **个人体验** | 拜访录入 ≤30 秒；行政填表时间显著下降；NPS 从「被迫用」到「主动用」 |
| **过程质量** | 现场即录；商机识别覆盖率上升；必填字段完整度上升；售后 10 秒内得答案 |
| **组织能力** | 新能力以天/周上线；多语种复用；对 SAP 零侵入；区域专家可共建 Agent |

## 用户故事速览：Maria 的一天

巴西区域资深销售 Maria（12 家三甲医院）在方案上线后的典型日：

| 时间 | 场景 | 主要 Agent |
| --- | --- | --- |
| 07:50 | 通勤：今日播报（拜访、风险商机、延期工单） | 指标分析 + 客户画像 |
| 08:55 | 到访前：客户画像速览 | 客户画像 |
| 10:30 | 拜访结束：一句话录入活动 + 商机草稿 | 客户拜访 + 商机评估 |
| 12:15 | 午餐：查订单物流 | 订单查询 + 物流查询 |
| 15:40 | 院内：故障知识检索 | 维修知识检索 |
| 18:20 | 酒店：双语日报草稿 | 工作总结 |

> 「今天我没有打过一个字。」
